# Шаблоны кейсов и отзывов учеников (promptica)

| Файл | Шаблон | Для чего | Длина отзыва для читаемости |
|---|---|---|---|
| `01.html` | Портрет + отзыв | ученик на фото, отзыв справа | до ~350 знаков |
| `02.html` | Результат + отзыв | работа ученика на всю ширину, отзыв под ней | до ~250 знаков |
| `03.html` | Чистый отзыв (белый) | только текст | до ~500 знаков |
| `04.html` | Чистый отзыв (красный) | то же, акцентный вариант | до ~500 знаков |

Как заполнить: в HTML заменить текст в блоках `.quote` (отзыв), `.name` (имя), `.res` (результат), фото положить в `img/NN-a.jpg` (NN = номер шаблона). Размер текста отзыва подбирается сам. Экспорт: `npm run export -- promptica-reviews`.
Для карусели кейсов: скопировать шаблон нужное число раз (`05.html`, `06.html`…), менять тексты и фото.

## Версия для сторис (1080×1920)
Папка `carousels/promptica-reviews-stories/` — те же 4 шаблона, раскладка перестроена под вертикаль. Текст и логотип держатся в безопасной зоне (верх от 270 px, низ до ~1500 px); фоновые фото могут вылетать за края. Рекомендуемая длина отзыва: шаблон 1 до ~300 знаков, шаблон 2 до ~220, шаблоны 3–4 до ~450. Экспорт: `npm run export -- promptica-reviews-stories`.
