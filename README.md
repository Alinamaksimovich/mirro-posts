# MIRRO — Instagram-карусели

Слайды делаются как HTML-страницы и превращаются в PNG **1080×1350** (формат 4:5) одной командой.

## Структура

```
carousels/            ← карусели: одна папка = одна карусель
  _example/           ← пример (папки с "_" в начале не экспортируются по умолчанию)
    01.html           ← один файл = один слайд (порядок по имени: 01, 02, 03…)
    02.html
shared/brand.css      ← цвета бренда, шрифты, базовые стили — общие для всех слайдов
scripts/export.js     ← скрипт экспорта в PNG
output/               ← сюда попадают готовые PNG (output/<карусель>/01.png …)
```

**Шрифты (Google Fonts, с кириллицей):** Cormorant Garamond (serif), Unbounded (жирный гротеск для заголовков), Manrope (мелкий текст).
**Цвета:** лайм `#D8F27F`, лаванда `#B9A8F0`, крем `#FAF8F6`, тёмный `#2C2C2A` — в CSS как `var(--lime)`, `var(--lavender)`, `var(--cream)`, `var(--dark)`.

## Как получить PNG

### Вариант 1 — попросить Claude (проще всего)
Напишите в сессии: «экспортируй карусель 01-trends». Claude запустит экспорт и запушит PNG в репозиторий — скачать их можно на GitHub из папки `output/`.

### Вариант 2 — на своём компьютере
Один раз: установить [Node.js](https://nodejs.org) (кнопка LTS), затем в папке проекта в Терминале:
```
npm install
npx playwright install chromium
```
Дальше каждый раз:
```
npm run export                 # все карусели
npm run export -- 01-trends    # одна карусель
```
Картинки появятся в `output/`.

## Как посмотреть слайд до экспорта
Откройте файл слайда (например, `carousels/_example/01.html`) двойным кликом в Chrome — увидите его в натуральную величину.
