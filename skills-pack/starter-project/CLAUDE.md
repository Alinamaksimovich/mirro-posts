# Карусели, сторис и видео-слайды: MIRRO и promptica

Рабочая заготовка. Два бренда, не смешивать: **MIRRO** (приложение, скилл `mirro-carousels`) и **promptica** (агентство, скилл `promptica-carousels`). Техника — `slides-export-pipeline`, вкус — `design-taste`. Все договорённости — `PLAYBOOK.md` (лежит в пакете; положи копию в корень проекта).

## Как устроено
- Карусель = папка `carousels/<NN-тема>/`, слайд = `01.html`, `02.html`…, фото — в `img/` рядом. Папки с «_» не экспортируются (эталоны `_ref-*`).
- Экспорт PNG: `npm run export -- <папка>` → `output/<папка>/`. Видео-слайд: `node scripts/render-video.js "<слайд.html>" <выход.mp4> [сек] [fps]`. Вырезка: `python3 scripts/cutout.py in.jpg out.png [допуск] [дырки]`.
- Шаблоны MIRRO: `TEMPLATES.md`. Общие стили MIRRO: `shared/brand.css`. Шрифты и логотипы: `assets/`.

## Правила работы
- Русский язык, без воды. Сначала концепция/черновик → правки пользователя → экспорт.
- Каждую версию смотреть глазами. Присланные фото и видео не обрезать самовольно.
- Каждая новая карусель MIRRO выглядит иначе предыдущих. promptica — по своей системе.
- Файлы всегда отправлять пользователю; после версии — коммит и пуш.
