# Ключевые моменты (playbook)

Всё, что мы выяснили и согласовали в работе над каруселями MIRRO и promptica. Если в новом аккаунте Claude что-то делает не так — проверь этот список: почти всегда ответ здесь.

## 1. Как мы работаем
- Язык — русский, ответы без воды. Профиль: директор AI-агентства, создаёт контент и продвигает агентство (текст для «Preferences» — `PREFERENCES.txt`).
- Порядок: **концепция/структура → черновик → правки → экспорт → подпись → коммит и пуш.** Пока пользователь просит «ничего не генерируй, только структуру» — картинки не делать.
- Расхождения в брифе называть сразу и предлагать решение (было: хук «6 признаков», слайдов 4 → взяли «4 признака»; «5 причин», причин 3 → «3 причины»).
- Если ответ пользователя противоречит смыслу макета (подписал «нормальным» фото, где ошибка) — расставить по смыслу, сказать об этом, предложить поменять. Пользователь принял.
- Что пользователь сохранил («не пересобирай, я сохраню черновики») — больше не трогать.
- Каждую версию **смотреть глазами** (контактный лист) до отправки; после правки — смотреть ещё раз.
- Каждый раз отдавать файлы в чат, не только говорить «готово». Кратко перечислить, что сделано и что осталось.
- Вопросы задавать только когда без ответа нельзя продолжать; остальное — разумный дефолт + пометка.

## 2. Два бренда, не смешивать
| | MIRRO (приложение) | promptica (агентство) |
|---|---|---|
| Цвета | лайм #D8F27F, лаванда #B9A8F0, крем #FAF8F6, тёмный #2C2C2A | **только** чёрный #0D0D0D, белый, красный #930400, кремовый #fff7e6 |
| Шрифты | Unbounded 900, Cormorant Garamond italic, Manrope, JetBrains Mono | Vela Sans, Old Soviet, Helvetica Neue Black Ext Obl, Helios Ext, Playfair Italic, Pangolin |
| Тон макета | смелый fashion-постер, цветные поля, плашки, рамки | тонко, воздушно, зерно, 35–45% пустоты |
| Скилл | `mirro-carousels` | `promptica-carousels` |
Старые цвета promptica (#B1202D, лайм, графит, голубой #95baeb) **не использовать**.

## 3. MIRRO — что нельзя забыть
- Бот **@Mirro_wardrobe_bot**; CTA: «ссылка на приложение — в шапке профиля».
- «В Telegram» в заголовках и слоганах → «в телефоне» / «под рукой». Слово «бесплатно» не писать. «Открыть в Telegram» не писать.
- Планера нет — **папки образов** («В отпуск», «Хочу», «Осень 2026»…).
- Нет логотипа — «MIRRO» набирается Unbounded 900.
- Каждая новая карусель — **другой шаблон** (A «Editorial Steps» → B «Журнальная панорама» → C «Хаос → порядок»), повтор только по просьбе.
- Сделано: «Как работает MIRRO» (A), «Примерь перед шопингом» (B), «Почему удобно» (C), рубрики сторис «Вопросы» (обложка + 5) и «О MIRRO» (обложка + 3).

## 4. promptica — что нельзя забыть
- Колонтитул: лого 34 px слева, справа 2 строки 19 px, поля 86 px; зерно `feTurbulence .9`, `multiply`, .16–.22.
- Выделение «как в редакторе» и стикеры — приёмы системы «AI SMM-система»; в «Слишком AI» пользователь от них отказался. Спрашивай или повторяй по брифу.
- Обучающие посты показывают «ошибка → направление», **без готовых промптов** (они для курса).
- Сделано: «AI SMM-система» (7 слайдов, слайд 1 — MP4), «Слишком AI» (6 слайдов, слайд 1 — MP4 в двух версиях: «ок» и «плохие» генерации).

## 5. Что нравится / не нравится (правки пользователя)
Нравится: смелая типографика, контраст «хаос → порядок», пары «✕ не ок / ✓ ок» с реальными фото, видео-нарезка на первом слайде, фото целиком в 9:16, аккуратные заметки на полях.
Не нравится (полный список — `skills/design-taste` → «Анти-вкус»):
- заголовок обложки в 3 строки → 2 строки;
- красные заметки справа вертикально → внизу слева горизонтально;
- зеркальный хромовый эффект по буквам («пластик») → мягкий блик;
- плотные широкие полосы на статичных слайдах promptica;
- **самовольная обрезка присланных фото/видео** → использовать кадрирование пользователя;
- белое сердечко 🤍 на макете;
- повтор шаблона предыдущей карусели;
- лишние стикеры/выделения, когда от них отказались.

## 6. Фото и видео
- Просить: вертикальные, **файлом**, ≥1000 px, без стикеров сторис и иконок, предмет целиком. Для пар — один сюжет в «плохой» и «хорошей» версиях.
- Пользователь присылает по 5 фото за сообщение — собирать пачками.
- Видео .MOV с iPhone — HEVC: в браузере не играет → кадры + массив длин планов (см. `slides-export-pipeline`).
- Нарезка из 4 планов — ритм по кадрам (4/3/4/3 или 6/4/5/4…), цикл целым числом повторов.
- 3:4 → 4:5 режет нижние 90 px; открытый вопрос: сделать все слайды карусели 3:4 (1080×1440), чтобы ничего не резать.
- Всегда предупреждать про стробоскоп (~7 смен/с) и предлагать замедление.
- Бренды на фото (ZARA, CHANEL, ARKET, H&M) — для рекламы заменять.

## 7. Технические ловушки
- Chromium в Playwright без HEVC/H.264-декодера: видео в HTML не проигрывать.
- Экспорт PNG не должен стирать MP4 (исправлено: удаляются только `.png`).
- Сторис — `data-size="1080x1920"` в `<body>`; панорама — `panorama.html` + `data-slides`.
- Шрифты из `assets/fonts` — `@font-face`; Google Fonts требуют сеть.
- Номер «04» шире «01»: заголовок рядом сдвигать (`left` ≥ 310).
- `aspect-ratio: 9/16` вместо фиксированной высоты кадра, когда фото показывают целиком.
- На видео-подложке читаемость — только через `scrim` (градиентное затемнение) + кремовый текст.
- Облачная сессия Claude Code требует чистого git-дерева — коммитить после каждой версии.

## 8. Чек-лист перед отправкой
1. Текст слово в слово из брифа; правки только согласованные.
2. Размеры: 1080×1350 / 1080×1920 / видео H.264 yuv420p.
3. Бренд: цвета, шрифты, логотип, колонтитул, CTA.
4. Нет наложений текста на лица, переносов-«висяков», вылетов за край; важное вне зоны интерфейса сторис.
5. Шаблон новый (MIRRO) или по системе (promptica).
6. Подпись `caption.md`, коммит, пуш, файлы отправлены.

- 3:4 вместо 4:5 для всей карусели с видео-слайдом.
- Замедлить ли смену кадров в видео-подложке.
