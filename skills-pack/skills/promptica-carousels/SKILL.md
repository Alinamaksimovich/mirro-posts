# promptica — карусели, видео-слайды

Агентство: **promptica — digital agency**, AI-контент для брендов (упаковка, соцсети, маркетплейсы, рекламные AI-видео). Тон: уверенный, конкретный, без «дешевле». Режим подачи — EXPERT/HYBRID из скилла `instagram-posts-premium` (хук → польза → мягкий CTA). **Если этот скилл расходится с `instagram-posts-premium` по цвету/шрифтам — приоритет здесь.** Перед версткой прочитай `design-taste` («Анти-вкус»), для техники — `slides-export-pipeline`.

## Айдентика (жёстко)
- **Только 4 цвета:** чёрный `#0D0D0D`, белый `#FFFFFF`, красный `#930400`, кремовый `#fff7e6`.
- **Нельзя:** `#B1202D`, лайм, графит, голубой `#95baeb` — ни в каком виде.
- Шрифты (файлы — `assets/fonts/`, подключать `@font-face`):
  - **Vela Sans** (ExtraLight 200 / Light 300 / Regular / Medium 500) — основной текст;
  - **Old Soviet** — заголовки «печатная машинка»;
  - **Helvetica Neue LT W06 Black Extended Oblique** — жирные капс-заголовки;
  - **Helios Ext C** — основной текст в системе «Слишком AI»;
  - **Playfair Display Italic** — красные заметки на полях;
  - **Pangolin** (Google Fonts) — рукописные заголовки.
- Логотип: `assets/logo_black.png` на светлом, `assets/logo_cream.png` на красном и чёрном; **высота 34 px**, слева вверху.
- Колонтитул на всех слайдах: слева лого, справа **две строки 19 px** — тема («AI SMM-система» / «Слишком AI») и `N / 07`. Поля **86 px**.
- Тон макета: тонко, воздушно, мелкий текст, **35–45% пустого места**, плёночное зерно. В статичных слайдах **никаких плотных широких полос и плашек на весь слайд**.
- На одном слайде: 1 главный приём + максимум 1 поддерживающий.

## Приёмы (спецификации)
- **Зерно** на каждом слайде: SVG `feTurbulence` `baseFrequency=".9"` `numOctaves=3`, поверх слайда, `mix-blend-mode: multiply`, `opacity .16–.22` (на красном .22). В видео — меняй `seed` каждый кадр (живое зерно).
- **Выделение «как в редакторе»**: ключевая фраза с фоном `rgba(147,4,0,.16)` (на тёмном/красном — `rgba(255,247,230,.18)`) и вертикальными курсорами ±3 px по краям (`box-shadow: -3px 0 0 0 цвет, 3px 0 0 0 цвет`, `box-decoration-break: clone`). Одно на слайд. **Если пользователь сказал «не надо» — не ставить.**
- **Стикер-вырезка** (PNG с прозрачным фоном): белый контур 4 px (4 `drop-shadow` по сторонам: `4px 0 0 #fff`, `-4px 0 0 #fff`, `0 4px 0 #fff`, `0 -4px 0 #fff`) + `drop-shadow(0 14px 16px rgba(0,0,0,.3))`, наклон 4–9°, ширина 25–45% кадра, **один на слайд**, можно заходить за край. Не нужны, если пользователь отказался.
- **Плашки-тезисы** (слайд-список): кремовые скруглённые, радиус ~24 px, 2–5 слов, вразброс вокруг рукописного заголовка.

## Система 1 — «AI SMM-система» (7 слайдов; 1 — MP4, 2–7 — PNG)
Эталон: `starter-project/carousels/_ref-promptica-ai-smm/`. Заголовки Old Soviet, текст Vela Sans Light, рукописное Pangolin.
- Фоны: 01 кремовый · 02 белый · 03 красный (зерно .22) · 04 чёрный · 05 кремовый · 06 белый · 07 красный.
- 01 (MP4, 6 с): «хотите, чтобы контент продавал?» печатается по буквам с красным курсором, затем выделение протягивается по «продавал?», появляется «листай →».
- 02 определение с выделением; 03 рукописный заголовок + 4 плашки-тезиса; 04 цитата Old Soviet на чёрном; 05 список 01–05 «лесенкой» с тонкими линиями; 06 «Если пропустить основу, то…» с красными акцентами; 07 CTA («напишите «система»», предложение по обучению).
- Стикеры лежат в `assets/sticker-NN.png` (NN = номер слайда).

## Система 2 — «Слишком AI» (6 слайдов, все кремовые; 1 — MP4)
Эталон: `starter-project/carousels/_ref-promptica-too-ai/`. Режим EXPERT: на каждом слайде **ошибка → направление**; готовых формулировок промптов и настроек **нет** (они для курса).
- Шрифты: заголовки Helvetica Neue Black Ext Obl капс; номер «01–04» красный, того же шрифта; текст Helios Ext; заметка Playfair Italic красная **внизу слева** (не справа, не вертикально).
- **01 хук (MP4)** — «ПОЧЕМУ ЭТО / «СЛИШКОМ AI»» в **2 строки** (3 строки — анти-вкус), подзаголовок «4 признака, которые выдают нейросеть», «листай →» справа внизу. Подложка — видео-нарезка: 4 кадра на весь слайд, склейки жёсткие, ритм по кадрам (24 fps). Сверху и снизу затемнение (`.scrim`), текст и лого кремовые, заголовок внизу слева, лица остаются свободными. Две версии: из «ок»-кадров и из «плохих» генераций.
- **02–05 — признаки:** `01 ПЛАСТИКОВЫЕ МАТЕРИАЛЫ`, `02 ОДИНАКОВАЯ РЕЗКОСТЬ`, `03 ИДЕАЛЬНАЯ СИММЕТРИЯ`, `04 СТРАННЫЙ СВЕТ`. Каркас: красный номер → заголовок (сам показывает ошибку) → **две рамки под фото: слева «✕ не ок», справа «✓ ок»** → под левой «ОШИБКА» + текст, под правой «НАПРАВЛЕНИЕ» + текст → заметка на полях.
  - заголовок-демонстрация: пластик — один мягкий блик по верху букв (зеркальный хром — анти-вкус); резкость — первое слово размыто (`blur 7px`), второе резкое; симметрия — заголовок строго по центру на красных линиях-разметке, последняя буква «я» выбита из сетки красным; свет — красная точка «источник» с лучом, у заголовка тень от этого источника, фон с мягким световым пятном.
  - **Фото:** по паре на слайд, файлы `img/NN-bad.jpg` / `img/NN-good.jpg` (NN = номер html-файла 02–05). Рамка по умолчанию 440×520, `object-fit: cover` + `object-position` (лицо в кадре). По просьбе «в полный рост 9:16» — `.ph { height:auto; aspect-ratio: 9/16 }`, номер и заголовок в одну строку сверху (номер 96 px, заголовок 52 px, `left` ≥ 310 для «04», пара с `top: 292px`).
  - **Что «ок», а что «не ок», определяй по смыслу слайда, а не по порядку присланных файлов.** Если подпись пользователя противоречит теме (например, «резко везде» названо «норм») — расставь по смыслу, скажи об этом и предложи поменять.
- **06 CTA** — «КАК ИМЕННО / ЭТО СДЕЛАТЬ», красным «разберём на нашем курсе», мелко «Анонс курса там же — подписывайтесь, чтобы не пропустить», заметка «→ подписаться».

## Видео-слайды (подложка-нарезка)
- Пользователь присылает нарезку (HEVC .MOV). Chromium в Playwright **не декодирует HEVC** → вытащи кадры ffmpeg в jpg, на странице показывай `<img>` по таймкоду (`window.setT(t, frame)`).
- Определи планы по скачкам разницы кадров (порог ~10): длины планов — это и есть ритм; одинаковые планы повторяются — храни 4 эталонных кадра + массив длин.
- Цикл: повтори нарезку целое число раз; склейка «конец → начало» должна быть такой же, как остальные. 24 fps при длине в 73 кадра → 2 прохода = 6,083 с = 146 кадров ровно. Для 14 кадров/24 fps → 10 проходов = 5,833 с на 30 fps.
- Видео 3:4 (1080×1440) в слайде 4:5 (1080×1350): верхнее выравнивание, обрезаются нижние 90 px; **не кадрировать самому присланные кадры** — используй кадрирование пользователя. Предложить альтернативу: все слайды 3:4.
- Звук в исходнике часто пустой (−91 dB) — проверь `volumedetect`, не тащи пустую дорожку.
- Предупреждать: ~7 смен кадра в секунду — стробоскоп.

## Процесс и чек-лист
1. Концепция/структура без генерации, расхождения брифа назвать (пример: в хуке «6 признаков», в слайдах 4).
2. Просить фото: пары «не ок/ок», вертикальные, файлом, ≥1000 px, без стикеров.
3. Черновик → осмотреть каждый PNG → отдать → правки → экспорт → коммит.
4. Перед отправкой: только 4 цвета; лого 34 px; колонтитул 2 строки 19 px; поля 86; зерно; воздух; заголовок без вылетов; заметка внизу слева; нет «выделений/стикеров», если от них отказались.
