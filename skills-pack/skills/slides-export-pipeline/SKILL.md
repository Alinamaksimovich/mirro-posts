# Экспорт слайдов, вырезка, видео

Скрипты лежат в `scripts/` этого скилла; в рабочем проекте — `scripts/` рядом с `shared/` и `carousels/` (заготовка — `starter-project/`).

## Установка (один раз)
```
npm install                      # playwright 1.56.1
npx playwright install chromium  # если нет Chromium (в облачных сессиях Claude Code он уже есть)
python3 -m pip install pillow    # для cutout.py и работы с фото
ffmpeg                           # для видео (проверить: ffmpeg -version)
```

## Структура проекта
```
carousels/<NN-тема>/  01.html 02.html …  img/  caption.md   ← одна папка = одна карусель
carousels/_ref-*/                                              ← папки с «_» не экспортируются
shared/brand.css      assets/fonts  assets/logo_*.png
output/<тема>/        01.png … (экспорт)   01.mp4 (видео-слайд)
```
Слайд — отдельный HTML, `body`/`.slide` ровно 1080×1350, `overflow:hidden`. Шрифты — `@font-face` из `assets/fonts` или Google Fonts `@import` (нужна сеть); экспорт ждёт `document.fonts.ready`.

## Экспорт в PNG
```
npm run export -- <папка-карусели>     # одна карусель → output/<папка>/NN.png
npm run export                         # все, кроме папок с «_»
```
- Размер по умолчанию 1080×1350; для сторис в HTML: `<body data-size="1080x1920">`.
- **Панорама:** если в папке есть `panorama.html` с `data-slides="5"`, это одно полотно (5×1080 × 1350), экспорт режет на 5 PNG + `panorama-preview.png`.
- Экспорт удаляет только старые `.png`, `.mp4` остаются.
- Файл с именем, начинающимся с «_», — заготовка; не экспортировать.

## Видео-слайд (MP4)
```
node scripts/render-video.js "<слайд.html>[?параметр=значение]" <выход.mp4> [секунды=6] [fps=30]
```
- Страница обязана определить `window.setT(t, frame)` — нарисовать состояние на момент `t` (секунды). Рендер делает скриншот на каждый кадр и кормит ffmpeg: H.264 high, `yuv420p`, crf 16, faststart.
- Число кадров = round(секунды × fps). Подбирай длину так, чтобы нарезка повторялась **целое число раз** (цикл Instagram бесшовный): `кадров_нарезки / 24 × повторов`. Пример: 73 кадра/24 fps ×2 = 6,083333 с, 24 fps = 146 кадров.
- Параметр в пути (`01.html?set=bad`) попадает на страницу — удобно для вариантов.
- Живое зерно: в `setT` меняй `seed` у `feTurbulence` от номера кадра.
- **Chromium не декодирует HEVC (.MOV с iPhone).** Не вставляй `<video>`; вытащи кадры: `ffmpeg -i in.MOV -vsync 0 f%02d.png`, найди планы по скачкам разницы соседних кадров (>10 из 255), оставь по одному эталонному кадру на план + массив длин планов, на странице переключай `<img>` по таймкоду.
- Проверь звук: `ffmpeg -i in.MOV -vn -af volumedetect -f null -` (−91 dB = тишина, дорожку не переносить).
- Проверка результата: `ffprobe` (кодек h264, размер, fps, число кадров) + кадры `ffmpeg -ss T -i out.mp4 -frames:v 1` в полоску-контактный лист.

## Вырезка предмета с фона
```
python3 scripts/cutout.py вход.jpg выход.png [допуск=26] [убирать_замкнутый_фон=1]
```
- Фон — светлый/тёмный однотонный (цвет берётся по углам), заливка от краёв.
- Допуск маленький (4–12) для белого на белом (футболка, топ); 18–26 для обычных.
- `убирать_замкнутый_фон=1` — убирает «дырки» (ручка сумки, пространство между лампой и монитором); `0` — если внутри предмета есть области цвета фона (белый принт, светлая ткань).
- Проверять всегда: наложить на цветной фон и посмотреть края и дырки.

## Подготовка фото
- webp → jpg через PIL; ширина ≤ 1000 px, `quality=90` (репозиторий не раздувать).
- Фото 9:16 (1080×1920): кадр 3:4 → вырезать окно 1440 по высоте; **окно выбирать по лицу/предмету, а не по центру**, но если пользователь прислал свою обрезку — использовать её.
- Со скринов убирать стикеры/иконки обрезкой.

## Проверка вёрстки (обязательно)
- После экспорта открыть каждый PNG; смотреть: переносы строк, наложения текста на лица, вылеты за край, читаемость на видео (затемнение `scrim`), неподгруженные шрифты.
- Для серии — контактный лист из 4–6 слайдов через PIL.
- Типовые ловушки: слишком широкий номер (`04` налезает на заголовок) — сдвинуть `left`; вертикальный текст `writing-mode` + `rotate(180deg)`; `aspect-ratio` вместо фиксированной высоты для кадра 9:16; `-webkit-background-clip:text` для эффектов по буквам.
