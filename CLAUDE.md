# MIRRO — Instagram-карусели

Отдельный проект: карусели для fashion-приложения MIRRO (цифровой гардероб с AI-примеркой, работает в Telegram).
Не связан с другими проектами пользователя.

## Как устроено
- Карусель = папка `carousels/<NN-тема>/`, слайд = `01.html`, `02.html`…, фото — в `img/` рядом.
- Экспорт в PNG 1080×1350: `npm run export -- <папка>` → `output/<папка>/`.
- Общие стили бренда: `shared/brand.css`. Шаблоны оформления: `TEMPLATES.md`.

## Бренд
- Цвета: лайм #D8F27F (главный акцент), лаванда #B9A8F0, крем #FAF8F6, тёмный #2C2C2A.
- Шрифты: Unbounded (жирный гротеск), Cormorant Garamond (курсив), Manrope (текст), JetBrains Mono (техподписи).
- Логотипа нет — название набирается Unbounded.
- Бот: @Mirro_wardrobe_bot. CTA: «ссылка на приложение — в шапке профиля» (не «открыть в Telegram»).
- Вместо планера в приложении — папки образов («В отпуск», «Хочу», «Осень 2026»).
- Тексты на русском, обращение на «ты».

## Правила работы
- Сначала концепция/черновик → правки пользователя → финальный экспорт.
- Каждая новая карусель должна визуально отличаться от предыдущих (шаблоны не повторять без запроса).
